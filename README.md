# 醸造百選リスト（案）ビューア

日本醸造学会が2026年10月6日付で発表した「醸造百選リスト（案）」を、スマートフォンで引けるようにした非公式のビューアです。

- 見る: https://y-kanno-sakenote.github.io/jozo-hyakusen/
- 50音順のリスト（96件）と都道府県別リスト（169件）を、日本地図と検索で引けます

## データについて

- 出典: 日本醸造学会「醸造百選リスト（案）」2026年10月6日（原本PDF: https://www.jozo.or.jp/gakkai/wp-content/uploads/sites/4/846dfab7233843a2067820ce7fb3c56b.pdf ）
- 名称・説明文・参照URLは原本のまま転記しています。内容は「案」の段階のものです。正式な内容は日本醸造学会の発表をご確認ください
- 本ビューアで足したのは、50音の行分けと、50音の品目と都道府県別の行の対応づけ（括弧を外した名称の一致、および原本の都道府県別リストの注にある「焼酎は本格焼酎・泡盛を指す」による読み替え）だけです
- 作成: 合同会社サケノテ（sakenote.net）。日本醸造学会の公式サイトではありません
